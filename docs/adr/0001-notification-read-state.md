# 通知の既読状態を Bluesky と共有する

macOS の通知タブと Dock は、アカウントごとに Bluesky が返す未読件数を使う。起動前の未読も初回取得で表示し、他の端末で読んだ分は次の更新で反映する。夜ミミズクでは、利用者が手前のウインドウでそのアカウントの通知一覧を見たときに既読を反映する。これにより、別のアプリを使っている間に背面の通知タブが更新されても、新着に気づける。

Dock には開いているアカウントの件数を合計し、同じアカウントを一度だけ数える。Dock の表示はサイドバーと個別に切り替えられる。Dock の設定の初期値は、既存の「未読バッジを表示」の設定を引き継ぐ。

手前の通知一覧に反映された最新の通知までを、そのアカウントでまとめて既読にする。全件をスクロールする必要はない。一覧を取得した後に届いた通知は、次に手前の一覧に反映されたときに既読の対象になる。

未読件数の取得に失敗したアカウントは、その起動中に最後に取得できた件数を合計に使う。まだ一度も取得できていないアカウントは、初めて取得に成功した時点で合計に加える。

既読の送信に失敗したときは、その操作によるバッジの減算を保留する。通信が戻ったら、そのアカウントで実際に一覧に反映した範囲まで再送する。再送を待つ間に届き、まだ一覧に反映されていない通知は未読のまま残る。
